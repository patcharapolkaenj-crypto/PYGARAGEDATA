# 🏍️ ระบบเช่ารถบิ๊กไบค์ & รถยนต์ (Rental App)

เว็บแอปจัดการข้อมูลลูกค้า รถ และรายการเช่า-คืนรถ พร้อมปฏิทิน
เขียนด้วย **Node.js + Express** (backend) และ **SQLite** (ฐานข้อมูล SQL แบบไฟล์เดียว ไม่ต้องติดตั้งเซิร์ฟเวอร์ฐานข้อมูลแยก)
หน้าเว็บเป็น HTML/CSS/JavaScript ธรรมดา ไม่มี build step แก้โค้ดแล้วรีเฟรชเบราว์เซอร์เห็นผลทันที

---

## 1) วิธีติดตั้งและรัน (ครั้งแรก)

1. ติดตั้ง [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป (ถ้ายังไม่มี)
2. เปิดโฟลเดอร์ `rental-app` นี้ด้วย **VSCode**
3. เปิด Terminal ใน VSCode (`Ctrl+` ` หรือเมนู Terminal > New Terminal`) แล้วรัน:

```bash
npm install
```

4. รันเซิร์ฟเวอร์:

```bash
npm start
```

5. เปิดเบราว์เซอร์ไปที่ **http://localhost:3000**

ระบบจะสร้างไฟล์ฐานข้อมูล `rental.db` ขึ้นมาอัตโนมัติในโฟลเดอร์นี้ตอนรันครั้งแรก — ไฟล์นี้คือฐานข้อมูล SQL ทั้งหมดของคุณ (ลูกค้า/รถ/รายการเช่า) เก็บอยู่ในไฟล์เดียว สามารถ backup ได้ด้วยการก็อปปี้ไฟล์นี้ไปเก็บไว้ที่อื่น

## 2) โครงสร้างไฟล์

```
rental-app/
├── package.json      # รายชื่อ dependency
├── server.js         # Express server + API endpoints ทั้งหมด + อัปโหลดรูป (แก้ตรงนี้เพื่อเพิ่ม/แก้ logic backend)
├── db.js             # โครงสร้างตาราง SQL (แก้ตรงนี้เพื่อเพิ่ม/แก้ field ในฐานข้อมูล)
├── rental.db          # ไฟล์ฐานข้อมูล SQLite (จะถูกสร้างอัตโนมัติ)
└── public/
    ├── index.html     # โครงหน้าเว็บทั้งหมด (6 เมนู: ภาพรวม / รายการเช่า / ปฏิทิน / รถ / ลูกค้า / ประวัติการเช่า)
    ├── style.css       # ธีมสี/ฟอนต์ทั้งหมด
    ├── app.js          # ตรรกะฝั่งหน้าเว็บ: เรียก API, แสดงตาราง, ฟอร์ม, อัปโหลดรูป, ปฏิทิน
    └── uploads/        # โฟลเดอร์เก็บรูปที่อัปโหลด (รูปลูกค้า/รูปรถ) — สร้างอัตโนมัติตอนรันครั้งแรก
```

### ฟีเจอร์หลักที่มีให้แล้ว

- **ลูกค้า**: รูปหน้าลูกค้า (อัปโหลดไฟล์จริงได้), ชื่อ, เบอร์โทร, บัตรประชาชน, ที่อยู่, Facebook/Instagram/TikTok, สถานะ Blacklist พร้อมเหตุผล, หมายเหตุ — แสดงเป็นการ์ด พร้อมปุ่มดู "ประวัติเช่า" ของลูกค้ารายนั้น
- **รถ**: รูปรถ, ประเภท (บิ๊กไบค์/รถยนต์), ยี่ห้อ, รุ่น, ทะเบียน, ราคา/วัน, สถานะ — คลิก "ดูรายละเอียด" เพื่อดูว่า **ใครเช่าอยู่ตอนนี้** (พร้อมข้อมูลลูกค้าเต็ม + วันเวลาส่งมอบ-กำหนดคืน) และประวัติการเช่าทั้งหมดของคันนั้น
- **รายการเช่า**: บันทึกวันที่ **พร้อมเวลา** (datetime) ทั้งวันส่งมอบ/กำหนดคืน/คืนจริง แก้ไข-เลื่อน-ยกเลิกรายการที่มีอยู่ได้ตลอดผ่านปุ่ม "แก้ไข"
- **ปฏิทิน**: แสดงรายการเช่าทั้งหมดแบบ visual (FullCalendar) สลับมุมมองเดือน/สัปดาห์ได้ คลิก event เพื่อแก้ไข
- **ประวัติการเช่า**: ตารางรวมทุกรายการ (กำลังเช่า/คืนแล้ว/ยกเลิก) พร้อมค้นหาและกรองสถานะ แสดงระยะเวลาเช่าที่คำนวณให้อัตโนมัติ

## 3) วิธี Custom ข้อมูล (เพิ่ม/แก้ไข field เอง)

ระบบออกแบบให้แก้ไขง่าย 3 จุด ต้องแก้ให้ครบทั้ง 3 จุดเวลาจะเพิ่มฟิลด์ใหม่:

1. **`db.js`** → เพิ่มคอลัมน์ใหม่ใน `CREATE TABLE` ของตารางที่ต้องการ (customers / vehicles / rentals)
   - ถ้าฐานข้อมูลเคยรันไปแล้ว ต้องลบไฟล์ `rental.db` ทิ้งแล้วรันใหม่ (ข้อมูลเก่าจะหาย) หรือเขียนคำสั่ง `ALTER TABLE ... ADD COLUMN ...` เพิ่มเองใน `db.js`
2. **`server.js`** → เพิ่มชื่อฟิลด์ใหม่ใน SQL `INSERT`/`UPDATE` ของ endpoint ที่เกี่ยวข้อง
3. **`public/app.js`** → เพิ่ม `<input>` ในฟังก์ชันสร้างฟอร์ม (เช่น `customerFormHtml()`, `vehicleFormHtml()`, `rentalFormHtml()`) และแสดงผลในตาราง/การ์ดตามต้องการ

💡 ทุกตาราง (customers, vehicles, rentals) มีคอลัมน์ `extra_data` (เก็บเป็น JSON string) ไว้ให้เก็บข้อมูล custom เพิ่มเติมแบบอิสระ โดยไม่ต้องแก้โครงสร้างตารางเลยก็ได้ ถ้าต้องการความยืดหยุ่นสูงสุด

## 4) API ที่มีให้ใช้งาน (ทดสอบผ่าน Postman/Thunder Client ได้)

| Method | Endpoint                    | คำอธิบาย                     |
|--------|------------------------------|-------------------------------|
| POST   | /api/upload                  | อัปโหลดไฟล์รูปภาพ (field name: `photo`) คืนค่า `{ url }` |
| GET    | /api/customers                | รายชื่อลูกค้าทั้งหมด (มี `?q=` ค้นหาได้) |
| POST   | /api/customers                | เพิ่มลูกค้า                   |
| PUT    | /api/customers/:id            | แก้ไขลูกค้า                   |
| DELETE | /api/customers/:id            | ลบลูกค้า                      |
| GET    | /api/customers/:id/rentals    | ประวัติการเช่าทั้งหมดของลูกค้ารายนี้ |
| GET    | /api/vehicles                 | รายการรถ (มี `?type=` `?status=` `?q=`) |
| POST   | /api/vehicles                 | เพิ่มรถ                       |
| PUT    | /api/vehicles/:id             | แก้ไขรถ                       |
| DELETE | /api/vehicles/:id             | ลบรถ                          |
| GET    | /api/vehicles/:id/status       | ผู้เช่าปัจจุบันของรถคันนี้ (ถ้ามี) + ประวัติการเช่าทั้งหมดของคันนั้น |
| GET    | /api/rentals                   | รายการเช่าทั้งหมด (มี `?status=` `?customer_id=` `?vehicle_id=` `?from=` `?to=`) |
| POST   | /api/rentals                   | สร้างรายการเช่าใหม่ (รถจะถูกตั้งเป็น "rented" อัตโนมัติ) |
| PUT    | /api/rentals/:id               | แก้ไข/เลื่อน/ยกเลิก/ปิดรายการเช่า (คืนรถ → รถกลับเป็น "available" อัตโนมัติ) |
| DELETE | /api/rentals/:id               | ลบรายการเช่า                  |
| GET    | /api/dashboard                 | ข้อมูลสรุปภาพรวม (รวมจำนวนลูกค้าติด Blacklist) |

**หมายเหตุเรื่องวันเวลา:** ฟิลด์ `start_datetime`, `end_datetime`, `actual_return_datetime` ในตาราง `rentals` เก็บเป็นข้อความรูปแบบ `YYYY-MM-DD HH:MM` (มีเวลาด้วย ไม่ใช่แค่วันที่)

## 5) สำรอง/ย้ายข้อมูล

ฐานข้อมูลทั้งหมดอยู่ในไฟล์ **`rental.db`** ไฟล์เดียว ต้องการสำรองข้อมูลแค่ก็อปปี้ไฟล์นี้ไปเก็บไว้ที่อื่น หรือย้ายเครื่องก็แค่ก็อปทั้งโฟลเดอร์ไปวางแล้ว `npm install` ใหม่

หากต้องการเปิดดู/แก้ไขข้อมูลในไฟล์ `rental.db` โดยตรงแบบ GUI แนะนำโปรแกรม [DB Browser for SQLite](https://sqlitebrowser.org/) (ฟรี)

---

## 6) จะ deploy ขึ้นใช้งานจริงบนอินเทอร์เน็ตยังไง?

โปรเจกต์นี้รันได้ทันทีบน hosting ที่รองรับ Node.js เช่น Render, Railway, Fly.io หรือ VPS ทั่วไป (แค่รัน `npm install && npm start` แล้วตั้ง reverse proxy/Nginx ชี้มาที่พอร์ต 3000) หากใช้งานพร้อมกันหลายคน/ข้อมูลเยอะมาก แนะนำให้พิจารณาย้ายจาก SQLite ไปเป็น PostgreSQL หรือ MySQL ในอนาคต ซึ่งโครงสร้าง SQL ใน `db.js` และ query ใน `server.js` สามารถแก้ไขให้ไปต่อกับฐานข้อมูลเหล่านั้นได้เช่นกัน
